# zls

Claude Code LSP plugin for [zls](https://github.com/zigtools/zls), a Zig language server.

## Features

- Zig completions
- Hover documentation
- Diagnostics
- Inlay hints and goto-definition

## Prerequisites

The `zls` binary must be installed and on your `PATH`. See the [zls install guide](https://zigtools.org/zls/install/) for options (Homebrew, Mason, build-from-source, etc.).
